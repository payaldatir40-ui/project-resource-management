# Project & Resource Management System

## Overview

A full-stack Project & Resource Management System developed using
Python, Django, Django REST Framework, Microsoft SQL Server,
HTML, Bootstrap, and JavaScript.

The system provides centralized management of employees, clients,
projects, and resource allocations.

## Features

### Employee Management
- Add employees
- View employees
- Update employee details
- Delete employees
- Employee status and department tracking
- Date of Joining (DOJ)

### Client Management
- Add clients
- View clients
- Update client details
- Delete clients
- Industry and client status tracking

### Project Management
- Create and manage projects
- Associate projects with clients
- Track project start and end dates
- Track project budget
- Track project status

### Resource Management
- Assign employees to projects
- Define employee roles
- Track allocation percentage
- Track allocation start and end dates
- Calculate employee utilization
- Identify overallocated employees

### Dashboard
- Total employees
- Total clients
- Total projects
- Active projects
- Total project budget
- Overallocated employees
- Resource utilization
